# PC4 - Control Estadístico de Procesos

**Assessment Industrial Analytics Challenge**
Guía para estudiantes

## 1. Objetivo

La PC4 simula una evaluación técnica empresarial. Puedes utilizar Excel, Minitab e IA. Se evaluará el razonamiento, la selección correcta de herramientas y la interpretación.

## 2. Ejemplo de examen

**Problema:** Amazon Robotics controla el peso de sensores. Cada hora se toman subgrupos de n=5.

| Subgrupo | X1   | X2   | X3   | X4   | X5   |
|----------|------|------|------|------|------|
| 1        | 54.8 | 54.9 | 55.0 | 54.7 | 54.9 |
| 2        | 55.1 | 55.0 | 54.9 | 55.2 | 55.1 |
| 3        | 55.2 | 55.3 | 55.1 | 55.2 | 55.4 |
| 4        | 55.5 | 55.4 | 55.6 | 55.5 | 55.4 |
| 5        | 55.8 | 55.7 | 55.6 | 55.8 | 55.7 |

**Se pide:** identificar la carta adecuada, resolver en Excel y Minitab Assistant, interpretar los resultados y explicar el apoyo de la IA.

## 4. Contenido del HTML

- Portada
- Descripción del problema
- Identificación de la carta
- Desarrollo en Excel
- Desarrollo en Minitab
- Interpretación
- Conclusiones
- Bibliografía e IA utilizada

## 5. Registro de prompts

Para cada prompt utilizado, registrar:

- **PROMPT**
- **Objetivo**
- **Respuesta de la IA**
- **¿Qué modifiqué?**
- **Reflexión personal**

## 6. Declaración de IA

Indicar herramientas utilizadas, porcentaje aproximado de apoyo de IA y declarar que la interpretación es propia.

## 7. Recomendaciones

- Se puede usar GitHub o servidores públicos.
- El ZIP será el medio oficial de evaluación.
- Verifique que `index.html` funcione localmente y que las imágenes se visualicen correctamente mediante rutas relativas.
